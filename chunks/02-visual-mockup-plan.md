# Chunk 02 - Visual Mockup Plan

Status: Ready

Goal: Define the first browser-based visual mockup scene for Stormlight Village.

Why this matters: The first mockup should prove the mood, composition, and identity before gameplay systems are added.

## Scene Goal

Create one full-screen browser scene showing Stormlight Village after a heavy storm.

## Required Visual Elements

- Damp forest village path.
- Damaged water wheel generator as the main focal point.
- Young apprentice civil engineer in the foreground.
- Cute floating AI companion robot near the character.
- Lantern glow as a key visual signal.
- Soft post-storm atmosphere: puddles, mist, wet leaves, broken branches, and flickering lamps.
- Hint of a gate or path that could open later after repairs.

## Composition Notes

The water wheel should be easy to identify from the first glance. The character and robot should be readable in the foreground. The scene should feel like a game screen, not a marketing page.

## Mockup Boundaries

- No gameplay yet.
- No collectible logic yet.
- No physics yet.
- No character selection screen yet.
- Simple animation is allowed if it helps the scene feel alive, such as drifting mist, soft lantern glow, blinking robot eye, or water movement.

## Next Steps

- Build the mockup in the browser.
- Review the look before adding gameplay.
